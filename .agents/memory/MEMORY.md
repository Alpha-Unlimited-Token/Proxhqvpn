- [Omega lib composite build](omega-lib-build.md) — lib/omega-api-client-react and lib/omega-api-zod must be in root tsconfig.json references or tsc --build won't emit their .d.ts files, breaking omega-dashboard typecheck.
- [Creating api-type artifacts](api-artifact-bootstrap.md) — createArtifact only supports: expo, data-visualization, mockup-sandbox, react-vite, slides, video-js. For a custom Express API server: scaffold dirs manually, bash-copy the edit.toml to artifact.toml to make the file exist, then call verifyAndReplaceArtifactToml.
- [pnpm catalog coverage](catalog-gaps.md) — pnpm-workspace.yaml catalog is sparse: express, helmet, pino, pino-http, express-rate-limit, @clerk/express, esbuild, @types/express, typescript are NOT catalogued. Copy explicit versions from api-server/package.json for new server artifacts.
- [Workspace lib @types/node pattern](lib-types-node.md) — any lib tsconfig with "types": ["node"] must also declare "@types/node": "catalog:" in its package.json devDependencies (pnpm strict isolation).
- [Mockup-sandbox vite config](mockup-sandbox-vite.md) — PORT and BASE_PATH must have fallback defaults (not hard throws) so vite build works without runtime env vars during deploy.
- [appendAuditEvent call signature](audit-chain-call-sig.md) — appendAuditEvent takes ONE AuditEvent object (not a string + object); returns ChainEntry synchronously, not a Promise — no .catch() needed.
- [drizzle-zod + zod v3 incompatibility](drizzle-zod-compat.md) — createInsertSchema from drizzle-zod returns Zod v4 types; z.infer<> from "zod" (v3) cannot accept them. Remove drizzle-zod dependency from lib schema files; use typeof table.$inferInsert/Select instead.
- [requireRbac middleware pattern](rbac-middleware.md) — requireRbac(action) in middlewares/requireRbac.ts reads users.role from DB; isAdmin=true maps to "owner" if no role stored; uses parseRole() from lib/rbac.ts; call after requireAuth so userId is guaranteed.
- [daemon-inbound per-node HMAC pattern](daemon-per-node-hmac.md) — verifyDaemonHmac() from lib/daemon-auth.ts accepts a getNodeSecret async callback; wire it by checking X-Node-ID header first then falling back to DAEMON_PSK; daemon_secret generated as crypto.randomBytes(32).toString("hex") on node creation.
- [SiemEvent interface shape](siem-event-shape.md) — SiemEvent is {actor, action, resource, result, ip?, metadata?, severity?}; NOT {type, severity, data}. severity values: low/medium/high/critical only (no "info"/"warning"). shipSecurityEvent is async — use void or await; never call without handling the promise.
- [registerAdminRoute capabilities whitelist](admin-route-capabilities.md) — registerAdminRoute.ts has an ADMIN_CAPABILITIES allowlist; any new capability used via registerAdminRoute must also be added there or the server throws at startup.
- [express-rate-limit IPv6 keyGenerator](rate-limit-ipv6.md) — any custom keyGenerator that falls back to req.ip must use ipKeyGenerator(req) from express-rate-limit, or ERR_ERL_KEY_GEN_IPV6 crashes the server at startup.
- [Cloud Run startup crash: module-level mkdirSync](cloudrun-mkdir-crash.md) — any fs.mkdirSync at module load time (top-level, in constructors instantiated at module level, or in bootstrap functions) will crash Cloud Run if the target path doesn't exist. Always wrap in try/catch. multer({ dest }) also calls mkdirSync — fall back to os.tmpdir() on restricted filesystems.
- [platform_events + control_plane_instances schema](platform-schema.md) — both tables use raw SQL (not Drizzle ORM) but ARE in Drizzle schema at lib/db/src/schema/platform.ts; never treat them as stale or drop them.
- [ghost_trap_rules schema location](ghost-trap-rules-schema.md) — ghostTrapRulesTable is defined in lib/db/src/schema/ghost-nodes.ts (not ghosttrap.ts). Columns: userId, ruleType (path_pattern|ua_pattern|header_pattern|ip_cidr), pattern, action (log|tarpit|block|silk_trap), priority, enabled, description, matchCount, lastMatchAt.
