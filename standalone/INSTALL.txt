QUICK INSTALL (Linux / macOS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  curl -fsSL https://proxhqvpn.app/install | bash

  This single command will:
    1. Detect your OS and CPU architecture
    2. Download the correct ProxhqVPN package
    3. Extract to ~/ProxhqVPN
    4. Remove macOS quarantine flags (if on macOS)
    5. Optionally install as a background service
    6. Open the dashboard in your browser

With options:
  curl -fsSL https://proxhqvpn.app/install | bash -s -- --port 8080 --dir ~/vpn

MANUAL INSTALL — FROM THIS PACKAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Linux / macOS:
    1. Extract this zip to your chosen folder
    2. Open Terminal in that folder
    3. Run:  ./start.sh
    4. Open browser: http://localhost:7474

  Windows:
    1. Extract this zip to your chosen folder
    2. Double-click: start.bat
    3. Browser opens automatically to http://localhost:7474

  Universal (any OS — requires Node.js 20+):
    1. Install Node.js 20+ from https://nodejs.org
    2. Extract this zip
    3. Linux/macOS: ./start.sh  |  Windows: start.bat

  │  • Beacon / Spider / Worm agents on every node                         │

CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Change port:
    PORT=8080 ./ProxhqVPN          (Linux/macOS)
    set PORT=8080 && ProxhqVPN.exe  (Windows cmd)

  Change data directory:
    PROXHQVPN_DATA=/path/to/data ./ProxhqVPN

  All data stored in data/proxhqvpn.db (SQLite).
  Back up this file to preserve your configuration.
  Delete it to reset to factory defaults (60 nodes re-seeded).

  • The terminal command set is restricted to safe read-only commands.

  • Rate limiting: 500 req/min global | 100/min writes | 30/min terminal
  • No telemetry, no cloud sync — all data stays on your machine.
