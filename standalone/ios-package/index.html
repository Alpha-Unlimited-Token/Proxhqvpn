Welcome to ProxhqVPN 🛡

This guide walks you through setting up ProxhqVPN on your iPhone or iPad. It takes about 5–10 minutes.

ℹ️ iOS note: Apple requires VPN configs to be imported through the WireGuard app. This guide walks you through each tap. No computer needed.
📋
What you need: iPhone or iPad (iOS 14+), a ProxhqVPN account
⚡
WireGuard VPN — fastest protocol, free from the App Store (GPLv2)
🌍
4 servers included — Los Angeles, Chicago, London, Tokyo
🔄
Switch servers anytime — no reinstall, just toggle in the WireGuard app
🧹
Zero logs — no traffic or connection times stored

ℹ️ This is a manual setup guide, not an automated installer. Each step requires a few taps. Everything is described clearly below.

Step 1 — Install WireGuard

Install the free WireGuard app from the App Store. This is the VPN engine ProxhqVPN uses.

🍎  Install WireGuard — App Store

Free · Open Source (GPLv2) · by Jason A. Donenfeld · Requires iOS 14+

📱 What you should see App Store → WireGuard page → blue "GET" button → tap it → authenticate with Face ID / Touch ID → app installs → tap "Open"
iOS 16+ users: After WireGuard installs, iOS will ask "Allow VPN Configurations?" when you first import a config. Tap Allow — this is required for any VPN app on iPhone.
🙋 I'm stuck — App Store won't let me install WireGuard▶
  • Age restriction? WireGuard is rated 4+. Check Screen Time / parental controls if the install is blocked
  • Requires iOS update? WireGuard needs iOS 14 or later. Go to Settings → General → Software Update
  • No Apple ID? You need a free Apple ID to download from the App Store. Create one at appleid.apple.com
  • Contact ProxhqVPN support

Step 2 — Sign In & Download Configs

Sign in to ProxhqVPN to get your personal WireGuard configuration files.

🔑 Sign In to ProxhqVPN

Opens in Safari. No account? Sign up free.

Download your configs

  1. 1
    After signing in, go to WireGuard Config (sidebar or proxhqvpn.com/wireguard)
  2. 2
    Tap "Download All Servers Pack"
  3. 3
    Safari shows a download prompt — tap Download
  4. 4
    The zip file saves to Files app → Downloads — come back here when done
💾 What you should see Safari download bar shows proxhqvpn-all-servers.zip completing → Downloads indicator (↓) in Safari toolbar turns solid
Safari tip: If tapping the button just opens the zip in the browser, long-press it and tap "Download Linked File" to save it to Files.

🙋 I'm stuck — Safari isn't downloading the file▶
  • Zip opens as a webpage? Long-press the download button → "Download Linked File"
  • Can't find the file? Open the Files app → Browse → iCloud Drive or On My iPhone → Downloads
  • Using Chrome or Firefox on iOS? Safari gives the best download experience. Try opening proxhqvpn.com/wireguard in Safari instead
  • Prefer to import one server at a time? Each server card on the WireGuard Config page has a "Download .conf" option

Step 3 — Import Configs into WireGuard

Import your downloaded configs into the WireGuard app. You can import all 4 servers at once.

Method A — Import from Files app (recommended)

  1. 1
    Open the WireGuard app
  2. 2
    Tap the + button (top right)
  3. 3
    Tap "Import from file or archive"
  4. 4
    In Files, navigate to Downloads → tap proxhqvpn-all-servers.zip
  5. 5
    A confirmation screen shows 4 configs → tap Import All
  6. 6
    iOS asks "Allow VPN Configurations?" — tap Allow and authenticate
📲 What you should see after import WireGuard app → 4 tunnel cards: "proxhqvpn-los-angeles", "proxhqvpn-chicago", "proxhqvpn-london", "proxhqvpn-tokyo" — each with a green toggle

Method B — Share from Files app

  1. 1
    Open the Files app → Downloads → tap & hold proxhqvpn-all-servers.zip
  2. 2
    Tap Share → scroll to find WireGuard → tap it
  3. 3
    WireGuard opens with import confirmation → tap Import All

Method C — QR code (single server)

  1. 1
    On your computer, go to ProxhqVPN → WireGuard Config → click Show QR Code
  2. 2
    In WireGuard iOS app, tap + → "Create from QR Code"
  3. 3
    Scan the QR code — config imports instantly. Repeat for each server.
🙋 I'm stuck — WireGuard can't find the file or iOS blocks it▶
  • Files app not showing Downloads? Tap "Browse" at the bottom → look under "iCloud Drive" or "On My iPhone"
  • iOS says WireGuard needs permission? Go to Settings → Privacy → VPN & Device Management → allow WireGuard
  • "Allow VPN Configurations" prompt? Tap Allow — this is a one-time iOS security prompt, completely normal
  • Only imported some configs? You can repeat the import process — WireGuard won't duplicate existing tunnels
  • Need fresh configs? Sign in at proxhqvpn.com/wireguard and re-download

✓ Setup Complete!

ProxhqVPN is ready on your iPhone or iPad. Here's how to use it.

🔌
Connect: Open WireGuard → tap the toggle next to any server → VPN icon appears in your status bar
🔄
Switch servers: Toggle OFF the current server → toggle ON a different one
⚡
Quick toggle: Add WireGuard to Control Center — Settings → Control Center → add "VPN & Device Management"
✅
Verify: Visit proxhqvpn.com/leaks to confirm your IP changed and no leaks exist
🌐
Dashboard: proxhqvpn.com/dashboard for stats and settings while connected

Tunnel mode note

Split Tunnel (default): Only VPN subnet traffic is tunnelled. Other apps run normally. AllowedIPs = 10.8.0.0/24

Full Tunnel: ALL internet traffic goes through VPN. In WireGuard, tap the tunnel → Edit → set AllowedIPs to 0.0.0.0/0, ::/0

🙋 I'm stuck — VPN won't connect or IP didn't change▶
  • Toggle spins but never connects? Try a different server (London, Chicago, Tokyo). The first server may be temporarily down
  • VPN key icon in status bar? That means iOS is connected — check proxhqvpn.com/leaks to verify
  • iOS keeps disconnecting? Settings → General → VPN & Device Management → tap your tunnel → enable "Connect On Demand"
  • Configs expired or keys rotated? Re-download fresh configs from proxhqvpn.com/wireguard
  • iPhone behind corporate MDM? Some MDM profiles block custom VPN configs. Contact your IT department or use a personal device
  • Contact ProxhqVPN support
