Step 1 — Install WireGuard

ProxhqVPN uses WireGuard as its VPN engine. Install it from the App Store — it's free.

⬇ Install WireGuard on the App Store

Free · Made by WireGuard Development Team · Requires iOS 15 or later

Already installed? Skip to the next step.
iOS 14 or earlier? Update to iOS 15+ first: Settings → General → Software Update

Step 2 — Sign In to ProxhqVPN

Sign in to your ProxhqVPN account. Your personal VPN configs generate automatically — one for each server location.

🔑 Sign In to ProxhqVPN

Opens in Safari. Don't have an account? Sign up free.

After signing in:

  1. 1
    Go to WireGuard Config in the left sidebar
  2. 2
    Tap Generate Config for each server, or use Show QR Code to scan directly with WireGuard
  3. 3
    The QR code method is the fastest on iPhone — no file download needed

Step 3 — Import VPN Configs

Two ways to import — QR code is the fastest on iPhone.

Option A — QR Code (Fastest)

  1. 1
    On your computer, open ProxhqVPN → WireGuard Config
  2. 2
    Click Show QR Code next to any server
  3. 3
    Open WireGuard on your iPhone → tap + → Create from QR code
  4. 4
    Scan the QR code — config imports instantly. Repeat for each server.

Option B — Import from File

  1. 1
    In ProxhqVPN → WireGuard Config → tap Download to save the .conf file
  2. 2
    The file saves to Files app → Downloads
  3. 3
    Open WireGuard → tap + → Import from Files and Archives
  4. 4
    Navigate to Downloads, select the .conf file — done
