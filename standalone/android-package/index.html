Welcome to ProxhqVPN 🛡

This guide walks you through manually setting up ProxhqVPN on your Android phone or tablet. It takes about 5 minutes.

📋
What you need: An Android phone or tablet, a ProxhqVPN account, and a few minutes
⚡
WireGuard VPN — fastest, most secure protocol. Free and open source (GPLv2)
🌍
4 servers included — Los Angeles, Chicago, London, Tokyo
🔄
Switch servers anytime from the WireGuard app — no reinstall, no wizard needed
🧹
Zero logs — no traffic, no browsing history, no connection times stored

ℹ️ This is a manual setup guide, not an automated installer. Each step requires a tap or two on your phone. Everything is described clearly below.

Step 1 — Install WireGuard

ProxhqVPN uses WireGuard as its VPN tunnel engine. Install it first from Google Play.

▶  Install WireGuard — Google Play

Free · Open Source (GPLv2) · by Jason A. Donenfeld

📱 What you should see Google Play → WireGuard app page → blue "Install" button → tap it → wait for install to finish → tap "Open"

No Google Play? Use F-Droid or APK

  1. 1
    Open the F-Droid link below and tap Download APK
  2. 2
    On your phone: Settings → Apps → Install unknown apps → allow your browser
  3. 3
    Tap the downloaded file to install
📦 WireGuard APK via F-Droid
🙋 I'm stuck — WireGuard won't install▶

Common fixes:

  • Check your internet connection and try Google Play again
  • If Play Store says "incompatible": your Android version may be below 5.0 — use the F-Droid APK instead
  • APK blocked by phone? Go to Settings → Apps → your browser → "Install unknown apps" → Allow
  • Still stuck? Contact ProxhqVPN support

Step 2 — Sign In & Download Configs

Sign in to your ProxhqVPN account to download your personal VPN configuration files.

🔑 Sign In to ProxhqVPN

Opens in your browser. No account yet? Sign up free.

After signing in — download your configs

  1. 1
    Tap WireGuard Config in the sidebar (or go to proxhqvpn.com/wireguard)
  2. 2
    Tap "Download All Servers Pack" — this downloads proxhqvpn-all-servers.zip with all 4 server configs inside
  3. 3
    The file saves to your Downloads folder — come back here when the download finishes

🙋 I'm stuck — can't find the download or the button▶
  • Make sure you're signed in — the config page requires an account
  • Try the direct link: proxhqvpn.com/wireguard
  • If the zip doesn't appear in Downloads, check your browser's download history (⋮ menu → Downloads)

Step 3 — Import Configs into WireGuard

Import your ProxhqVPN configs into the WireGuard app. You can import all 4 servers at once from the zip file.

Method A — Import from file (recommended)

  1. 1
    Open the WireGuard app
  2. 2
    Tap the blue + button in the bottom-right corner
  3. 3
    Tap "Import from file or archive"
  4. 4
    Navigate to Downloads → tap proxhqvpn-all-servers.zip
  5. 5
    All 4 configs appear in WireGuard — each as a separate server card
📲 What you should see after import WireGuard app → 4 tunnel entries: "proxhqvpn-los-angeles", "proxhqvpn-chicago", "proxhqvpn-london", "proxhqvpn-tokyo" — each with a toggle switch

Method B — Scan QR code (single server)

  1. 1
    On your computer, go to ProxhqVPN → WireGuard Config → click Show QR Code on any server
  2. 2
    In the WireGuard app, tap + → "Scan from QR code"
  3. 3
    Point your camera at the QR code — the config imports instantly
🙋 I'm stuck — can't find the zip or import fails▶
  • Can't find the zip? Open your phone's Files app → Downloads folder
  • Import says "no tunnels found"? Make sure you downloaded the all servers zip, not just a webpage
  • Only see .conf files? That's fine — import them one at a time with the same "Import from file" option
  • WireGuard says permission denied? Allow file access when prompted, or move the zip to Internal Storage first
  • Need fresh configs? Sign back into proxhqvpn.com/wireguard and re-download

✓ Setup Complete!

ProxhqVPN is ready on your Android device. Here's how to connect and switch servers.

🔌
Connect: Open WireGuard → tap the toggle next to any server → VPN connects in seconds
🔄
Switch servers: Toggle OFF the current server → toggle ON a different one
✅
Verify connection: Visit proxhqvpn.com/leaks to confirm your IP changed and no leaks exist
🌐
Dashboard: While connected, open proxhqvpn.com/dashboard for stats and settings

Tunnel mode note

Split Tunnel (default in configs): Only ProxhqVPN traffic routes through the VPN. Other apps run at full speed. AllowedIPs = 10.8.0.0/24

Full Tunnel: ALL traffic goes through VPN. In WireGuard, edit the tunnel → change AllowedIPs to 0.0.0.0/0, ::/0

Open ProxhqVPN Dashboard → 📖 Full User Guide
🙋 I'm stuck — VPN won't connect or IP didn't change▶
  • Toggle shows "Connecting…" forever? The server endpoint may be temporarily unreachable. Try a different server (London, Chicago, etc.)
  • Android VPN permission dialog? Tap "OK" — Android asks once to allow VPN connections
  • IP didn't change? Check proxhqvpn.com/leaks — if your real IP still shows, try toggling the tunnel off and on again
  • Configs expired? Your keys may have rotated. Re-download fresh configs from proxhqvpn.com/wireguard
  • Contact ProxhqVPN support
