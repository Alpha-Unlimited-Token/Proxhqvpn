ProxhqVPN Setup — Alpha Unlimited Technologies LLC
===================================================

SYSTEM REQUIREMENTS
-------------------
  - Windows 10 (version 1903 or later) or Windows 11
  - Internet connection required
  - Administrator privileges required
  - 150 MB free disk space

HOW TO INSTALL
--------------
  1. Extract this ZIP file to any folder on your computer.
  2. Right-click "setup.bat" and choose "Run as administrator"
     (Or just double-click — it will ask for admin rights automatically).
  3. Follow the on-screen wizard to complete installation.
  4. WireGuard VPN will be downloaded and installed automatically.
  5. A desktop shortcut to ProxhqVPN will be created.
  6. Click Finish — you're ready to go!

WHAT GETS INSTALLED
-------------------
  - WireGuard VPN client (official, from wireguard.com)
  - ProxhqVPN desktop launcher (shortcut + Chrome app window)
  - Start Menu entry: Start > Alpha Unlimited Technologies > ProxhqVPN
  - Optional: Desktop shortcut

UNINSTALLING
------------
  Go to: Settings > Apps > ProxhqVPN > Uninstall
  WireGuard can be removed separately via Settings > Apps > WireGuard
